# Double Life

Рабочий прототип многопользовательского шпионского симулятора в Roblox. Это **M0 — первая интерактивная сцена**, а не готовая игра.

## Запуск в Roblox Studio

Исходники хранятся как Rojo-проект (Luau). Нужны Roblox Studio, установленный Rojo CLI и плагин Rojo для Studio.

1. Склонировать репозиторий и открыть терминал в его корне.
2. Выполнить команду: `rojo serve default.project.json`
3. Открыть Roblox Studio, подключить плагин Rojo к работающему серверу и выполнить синхронизацию.
4. В Studio запустить **Test → Start Server → 2 Players**. Для контрразведчика использовать 3 игроков.

Альтернатива: `rojo build default.project.json -o DoubleLife.rbxlx`, затем открыть полученный файл в Studio.

## Что уже можно проверить

- Роли выдаются сервером; каждый клиент получает только свою роль.
- Первый игрок — владелец. Он может временно открыть кабинет через пульт в коридоре.
- Второй игрок — шпион. Он может открыть боковое окно, пробраться в кабинет, украсть досье из сейфа и вернуться к главному выходу.
- Третий игрок — контрразведчик. Он может лично проверить журнал в кабинете.
- Все роли могут осмотреть три картины в холле. Это пока лишь счётчик поручения, **не выдача постоянной валюты**.
- Владелец и другие игроки **не получают уведомления**, когда шпион крадёт документы: пропажу нужно заметить при осмотре сейфа или журнала.
- После успешного побега шпиона состояние досье сбрасывается для повторного теста через восемь секунд.

Стены, комнаты и интерактивные объекты M0 генерируются серверным скриптом из простых Roblox Part. Они предназначены исключительно для проверки механик; полноценный особняк создадим после тестирования игрового цикла.

## Принципы

- Проверка ролей и взаимодействий производится на сервере.
- Скрытые роли не помещаются в реплицируемые атрибуты персонажей.
- Игроки сами замечают происшествия и делают выводы. Система не назначает виновных.
- Действия должны быть полезны и интересны без обязательного чата.

Концептуальные решения и границы первой версии — в docs/CONCEPT.md.

## Ближайший этап

M1: NPC-охранник с патрулированием и реакцией на шум; ограниченные распоряжения владельца; действия персонала и заявки гостей. Затем — физические улики, подставы и внутриигровые мероприятия.

## Проверка

Автоматическая сборка и тестирование в Roblox Studio пока не запускались. Перед объединением изменений нужно выполнить сборку Rojo и тест с несколькими клиентами в Studio.
