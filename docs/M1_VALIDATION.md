## Реальный Roblox Studio

Studio **0.745.462.7451125**, Windows. Сборки открывались с диска G:. Запущены сервер и пять локальных клиентов.

Первый движковый прогон без владельца подтвердил: физическое патрулирование, серверное владение NPC, движение к месту шума, отклонение повтора, возврат к патрулю, обязательный перерыв, физическую доставку сока NPC, отвлечение охранника обслуживанием, отсутствие телепортаций и восстановление после недостижимой точки. Вывод сервера: `M1 STUDIO SUITE PASS`. Пять клиентов отдельно сообщили `M1 CLIENT AUDIT PASS`.

Сквозной сценарий использует тестовый RemoteFunction только для управления входом тестового клиента. Само действие идёт через `ProximityPrompt:InputHoldBegin/End` и обычные серверные проверки; проверяются реальные серверные последствия, а не ответ клиента «выполнено». Для воспроизводимости тест перемещает игроков к точкам. NPC никто не переставляет.

Финальный прогон движковой части: `M1 STUDIO SUITE PASS 5 clients`, 15:17:55 МСК. После исправления наложения тестовых персонажей у пульта/столика актуальный `tests/studio/Playthrough.luau` повторно запущен серверным Script в том же сеансе Studio с очищенными тестовыми заявками и счётом. В 15:26:41 МСК получен `M1 PLAYTHROUGH PASS`.

## Оставшиеся ручные проверки

Полный маршрут пешком с обычным управлением, комфорт нескольких подсказок у пульта, баланс времени отвлечения, задержки настоящей сети, мобильное управление и визуальная оценка всех следов. Отдельно пройти чтение журнала контрразведчиком и три картины, закрытие/открытие двери при столкновении с игроком, временную живую блокировку пути. Инструкции и ожидаемые состояния — `M1_TESTING.md`.

В логах Studio есть ошибки встроенных HTTP/аватарных сервисов для локального placeId=0/отрицательных тестовых UserId. Их следует отличать от `CreatorError` скриптов проекта; это не свидетельство успешности игровых тестов. Проверки M1 подтверждаются только собственными PASS-маркерами и наблюдаемым состоянием.
