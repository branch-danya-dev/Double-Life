## Исправления, найденные физическим прогоном

- На спуске по восточной лестнице R15 застревал у ступеней. Ступени сохранены визуально; столкновение задаёт непрерывная поверхность 26.6°. Повторный обход прошёл оба этажа и спуск.
- NPC с R6-ногами использовал дополнительный HipHeight 2, зависал выше пола и терял waypoint у верхней площадки. HipHeight 0 соответствует этому rig. После исправления помощник физически доставил заказ в архив, охранник продолжил патруль; телепорты не применялись.
- Планировщик с разрешённым прыжком иногда выбирал верх перил у дверного угла. Для NPC и автоматической ходьбы отключены прыжковые сокращения пути; непрерывные лестницы проходят без прыжка. Способность обычного игрока прыгать сохранена, защитная проверка закрытого кабинета выполняется с прыжками.
- Старый предел высоты сброшенной пломбы относился к M5. `World:dropPoint` теперь определяет реальный пол лучом; пломба и социальные предметы остаются на текущем этаже. Регрессионный сценарий собирает/кладёт их наверху.
- Диагностическая fixture обращалась к стойке ткани вместо самого переносимого предмета. Исправлено обращение; серверные условия взаимодействия сохранены.
- При накопившихся исторических окнах Studio показал Low System Resources. Старые временные сцены сохранены на G: и закрыты; последующие прогоны запускаются с освобождёнными ресурсами. Это ограничение локального процесса, не результат 15-клиентного теста.

## Ограничения

Desktop first-person, открытие/закрытие H/K, недоступность Robux и штатное возрождение в приёмной проверены визуально: [снимок](evidence/M6-first-person-shop-off.png). После автоматического Scriptable-режима тестового драйвера локальная прозрачность тела может требовать штатного Respawn перед ручным осмотром; свежий персонаж показал нормальный first-person. Драйвер отсутствует в production-сборке.

**Touch: NOT TESTED** — Device Simulator неактивен в этой многоклиентной сессии. **Полный gamepad-проход: NOT TESTED** — [Controller Emulator открыт](evidence/M6-controller-emulator.png), но одного открытия и короткого ввода недостаточно, чтобы подтвердить управление всем маршрутом. Реальные мобильное устройство/контроллер и mobile FPS не проверялись.

Техническая интеграция использует реальные клиенты с автоматическим пешим драйвером. Штатные spawn/reset между раундами допустимы; внутри маршрутов нет тестовых телепортаций. Детерминированные роли и место реликвии заданы только fixture; длительности 12/420/25/12 не ускорены. Blackout вызывается напрямую для проверки сцены; анонимный случайный триггер покрыт прежними M3-проверками.

Real DataStore: **NOT TESTED**. Paid shop: **DISABLED**. Ни production-хранилище, ни реальные покупки не использовались. Изолированный опубликованный тест сохранений/чеков остаётся release gate. Полные человеческие матчи, экономика, финальный арт и релизная оптимизация — M7/M8.
