# M7: проверка оформления и атмосферы

Дата: 2026-11-03 (Europe/Moscow, журналы UTC). База M6 `91a9a16`, ветка `feat/m7-art-deco-and-atmosphere`, Draft PR в `feat/m6-functional-mansion`. Предыдущие PR не объединяются. Направление: согласованные ар-деко и сдержанная мистика; объём — M7 дорожной карты #12.

## Автоматические проверки

**1796 assertions PASS = 1731 неизменённая проверка + 65 новых.** Девять прежних тестовых файлов и `MansionLayout` сохранены. Новый набор проверяет геометрию декора, палитру, бюджеты, идентичность комнат, семь размеров экрана, словарь меню и обратную связь только из личного снимка.

Luau 0.745: компиляция всех `src/tests`, анализ pure-модулей. Rojo 7.7.1: четыре сборки — production, многопользовательский сценарий, отдельная нагрузка и визуальный осмотр. Проверка production исключает тестовые драйверы, память вместо DataStore и обзорный RemoteEvent. Манифест оригинальных источников проверяется по SHA-256 с нормализацией UTF-8 LF. Лог: [M7-automated.log](evidence/M7-automated.log). SHA и ссылки GitHub Actions фиксируются в описании PR.

Дополнительно проверяются неопределённые имена в runtime-модулях (с явным списком Roblox globals; это не полный Roblox type-check) и структура трёх тестовых сборок. У каждой ровно один неисполняющий Main, единственный Runner с MemoryStore и проверка фактического адаптера при старте.

## Воспроизведение Studio

```sh
rojo build atmosphere-tests.project.json -o DoubleLife-M7-tests.rbxlx
rojo build atmosphere-review.project.json -o DoubleLife-M7-review.rbxlx
rojo build atmosphere-load.project.json -o DoubleLife-M7-load.rbxlx
```

В первой сцене запустить Server & Clients: 5 клиентов. После `M6 FIVE CLIENTS PASS` добавить 5; после `M6 LARGE CLIENTS PASS` добавить ещё 5. Используется прежний физический сценарий M6 с дополнительными M7-аудитами. Метки `M6` обозначают повторное выполнение сценариев, а не старый исполняемый код. Нужны обычные длительности Countdown/Active/Council, без ускорения.

Review — Test одного клиента. Она удерживает Waiting и даёт кнопки обзора комнат, включения аварийного света и возврата к обычной камере. Обзор перемещает только камеру: это визуальная проверка, не доказательство проходимости. Load — отдельный сервер с 15 клиентами: добавлять по пять через Test → Add Clients; стенд ждёт до 10 минут, затем запускает обычный Countdown и одновременные физические маршруты. В этих сценах production Main исключён через `globIgnorePaths` и заменён пустым выключенным скриптом. Профиль обслуживает MemoryStore; Runner и M7Audit проверяют это утверждение в работающем сервере. Реальные хранилище и покупки не вызываются.

## Проверка интерфейса и оформления

- Desktop: открытие правил/профиля/статуса через общее меню, закрытие, один активный экран, прокрутка длинного текста. Стандартный режим камеры в Waiting/Results, первое лицо в Active.
- iPhone XR Device Simulator: узкий портретный и короткий альбомный экран, открытие меню, чтение правил и перелистывание кнопками ↑/↓. Само меню меняет число колонок без уменьшения 44-px целей. После смены ориентации панели пересчитывают размеры.
- Жест перетаскивания через инструмент автоматизации дал неполный результат; полноценный touch-swipe не заявляется проверенным. Для длинных панелей есть проверенный доступ через кнопки страниц. Физический телефон не использовался.
- Controller Emulator: Select → Menu, A → открыть, D-pad → Profile, A → профиль, B → закрыть ([журнал выбора](evidence/M7-Studio-controller.log)). Проверены виртуальные кнопки эмулятора; это не полный матч на физическом геймпаде. Снимок профиля в этой ранней проверке показывает состояние недоступности; окончательная сцена отдельно подтверждает `FakeMemory` и `Ready`.
- Вечернее освещение, тёплая палитра и аварийный режим осмотрены в Studio. Основные лампы переходят на 0.1, аварийные остаются включёнными; обычная яркость точно восстанавливается. Загрузка встроенных аудиоресурсов подтверждена клиентским аудитом; субъективный аудиомикс требует плейтеста.

## Изменения по результатам осмотра

- Потолочные розетки были внутри потолочного перекрытия; опущены ниже поверхности. Добавлены верхние латунные филёнки, сохранены размеры M6-проёмов.
- Первоначальный свет пересвечивал стены; уменьшены мощность основных и аварийных источников, сохранён свет при отключении.
- Основа Billboard-таблички закрывала часть букв; опорная деталь теперь прозрачна. Стены продолжают скрывать надписи за собой.
- Поздние клиенты получали начальный размер камеры 1×1. Панели теперь ориентируются на реальный размер ScreenGui и отслеживают смену CurrentCamera.
- На коротком экране меню размещает кнопки в две колонки; на узком — в одну. Размер нажатия не уменьшается ниже 44 px. Длинные панели прокручиваются, высота текста рассчитывается по ширине.
- При проверке кода устранена лишняя подписка внутри загрузки цены. Подписки интерфейса создаются однократно при запуске клиента.
- Добавлены явные кнопки страниц длинных панелей и поднят слой HUD над мобильными элементами передвижения. После старта сервера 00:05 UTC также уменьшены яркость основных ламп с 0.65 до 0.5 и радиус с 34 до 24. Эти последние настройки проверены в review-сцене и отдельной load-сборке; геометрия и механика раундов не менялись.
- Найден конфликт стартовых скриптов в унаследованном способе описания fixture: вложенный `Main` с `Disabled=true` добавлялся рядом с Main из `$path`, а не заменял его. Это давало гонку между DisabledStudio и FakeMemory. Production Main теперь явно исключён из M7 fixtures; XML-аудит запрещает дублирование. Production DataStore оставался выключенным. После исправления повторно завершены сценарии 5/10 и отдельно проверен готовый профиль в review.

## Границы приёмки

Это техническая интеграция и визуальная проверка. Полные человеческие матчи, баланс, замеры FPS/памяти на физических телефонах и консолях остаются M8. Эмулятор экрана не подтверждает производительность физического телефона. Полный матч на физическом контроллере не проверялся.

В локальных клиентах Studio 0.745 наблюдаются ошибки штатного legacy `ChatScript:116` / `CoreGuiChatConnections`, `CreatorType` и зависимых CoreGui-модулей локального неопубликованного опыта. Они сохранены в журнале, не выдаются за нулевой engine-error запуск. Ошибка чата может оставлять его стандартную панель поверх HUD; проверку конфигурации чата в опубликованном тестовом опыте следует включить в M8. Таблички помещений под некоторыми углами частично скрываются геометрией; читаемость навигации также требует человеческого плейтеста.

Новая оболочка меню имеет RU/EN; прежние игровые тексты остаются русскими. Звук выключен при входе, встроенные Roblox-звуки служат тихими сигналами и фоном. Оригинальный саундтрек и озвучка не заявляются. Инвентарь, права и бюджеты: [M7_ART_DIRECTION.md](M7_ART_DIRECTION.md), [манифест](../assets/M7-manifest.json).

**Real DataStore: NOT TESTED. Paid shop: DISABLED.** Проверка изолированного опубликованного опыта перед Robux остаётся обязательной; production-данные не использовались.
